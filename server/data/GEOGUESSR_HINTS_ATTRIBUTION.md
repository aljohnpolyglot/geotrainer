# GeoGuessr hints dataset

`geoguessr-hints.json` is the generated `docs/countries.json` dataset from
[danielzaiser91/geoguessr-hints](https://github.com/danielzaiser91/geoguessr-hints),
revision `4679590d57f5c38880eeca9176dec84e1ab5f9ba`.

The upstream project describes the hints as primarily distilled from the Plonk It Guide
and licenses its derivative dataset under CC BY-NC-SA 4.0. Source URLs remain attached
to retrieved hints.
